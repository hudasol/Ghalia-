# Ghalia | The Curated Olfactory Experience

### The Curated Olfactory Experience for Luxury Hospitality

Ghalia is a bespoke, high-end scent-management platform engineered for luxury hospitality environments. Moving beyond simple diffusion, Ghalia integrates physiological research with real-time environmental control to transform atmosphere into a measurable, brand-aligned asset.

---

## ✦ The Vision

Ghalia operates at the intersection of Olfactory Science and Predictive Analytics. By leveraging data-driven correlations between ambient scent profiles and guest behavior (Scent-to-Spend), the platform optimizes sensory ROI through empirical intelligence.

### Key Pillars

* **Quiet Luxury Aesthetic:** A meticulously crafted interface utilizing a deep crimson and gold-etched palette.
* **Neuroscience Integration:** Scent libraries grounded in clinical research, targeting Linalool-GABA receptor interactions and Noradrenergic stimulation.
* **Precision Control:** Granular multi-zone management with real-time status monitoring across resort infrastructures.
* **Bespoke Intelligence:** Advanced KPI tracking and high-fidelity business impact visualization.

---

## 🛠 Technical Architecture

### Frontend Excellence

* **Engine:** Vite + React (SPA Architecture)
* **Styling:** Tailwind CSS with a customized Design System.
* **Motion:** Framer Motion for fluid, organic transitions.
* **Components:** Localized Radix UI for uncompromised accessibility and bespoke styling.

### Data & State

* **State Management:** React Context API + TanStack Query (v5).
* **Visualizations:** Recharts for sophisticated business impact analytics.
* **Icons:** Lucide-React (Customized stroke weights).

## 🚀 Installation & Local Development

To initialize the Ghalia environment locally, ensure you have **Node.js (v18+)** installed.

### 1. Environment Setup
```bash
git clone https://github.com/your-repo/ghalia-app.git
cd ghalia-app
```

### 2. Dependency Resolution
```bash
npm install
```

### 3. Cleanup Legacy Proxies
```bash
npm prune 
```

### 4. Initialize Development Suite
```bash
npm run dev
```
